Config is a plain schema_version1 object containing ONLY schema_version, run_id (32 lowercase hex), capability_sha256 (exactly two distinct64-lowercase-hex SHA256 values). Internal counter keys may be documented in handoff before a consumer is released. Optional CLI accepts a single explicit config JSON under its owned cwd and prints redacted bounded snapshots only; no implicit config/profile/environment reading.

No configurable destination, DNS/discovery/proxy/public bind, HTTP redirect, upstream info/LAN port or native launcher. One complete binary WS message = one byte-identical raw datagram, no envelope or ENet/game parsing. Replies only from the connected exact source tuple; one WS per distinct UDP source tuple. A send callback failure terminates, never claim delivery from queued bytes. Component tests may use a clearly labeled synthetic UDP endpoint at the exact upstream port; echo is not game proof.

## Admission

Exact GET raw URL /enet?cap=<canonical22base64url>, no extra/duplicate/encoded parameters. Host exactly127.0.0.1:29865; Origin exactlyhttp://127.0.0.1:29866; version13; exactly one Sec-WebSocket-Protocol outbreak-enet-dgram.v1. Reject duplicate/missing/null headers and nonmatching method/route/version/origin/protocol/host/capability before UDP allocation. Sec-WebSocket-Extensions request may be absent OR exactly 'permessage-deflate; client_max_window_bits' (the browser-native mandatory offer); any other/duplicate offer is rejected. Never negotiate it: perMessageDeflate=false and response must contain no Sec-WebSocket-Extensions, receiver must still reject compressed/RSV frames. 'No extensions' means no negotiated extension, not rejection of the standard browser offer. Library retains RFC key/masking/framing validation; no handwritten frame parser. Capability comparison hashes canonical string, safe fixed-size digest comparison. Reserve session and consume cap atomically once; any later failure burns token. No refresh/reconnect API. Redact URL/token from logs/snapshots/errors; no credentials/accounts/cookies.

At most2 active admitted sessions, at most4 retired UDP sockets held/discarding for60s to avoid immediate tuple reuse; at most6 UDP total. Admission fails if retirement capacity unavailable. At most4 pending accepted TCP sockets,2s header/upgrade deadline,8 upgrade attempts/run; HTTP maxHeaderSize8192. Bounded HTTP rejection then destroy. No ordinary HTTP content. Log reject reason rather than raw header/URL. Track active/pending/retired sockets through error/late callback races; whole close destroys all immediately and prevents new starts on closed instance.

## Frozen resource policy

Binary payload2..4096 bytes. ws maxPayload4096/maxFragments16/maxBufferedChunks32/perMessageDeflate=false/skipUTF8Validation=false/autoPong=false/closeTimeout1000. ENet may use tiny ACKs;576 is not minimum message length. No wire/datagram transformation or silent unreliable dropping to hide saturation.

Per direction per session token buckets256 datagrams/s burst64 and512KiB/s burst128KiB. Enforce before own copy/forward; first violation terminates1008. Node UDP pending sends<=64 AND128KiB until callbacks; WS bufferedAmount plus own pending bytes plus new size<=128KiB. Oldest outstanding send/backlog<=500ms; no unbounded second queue. Counters must release once across callback/error/close; retain diagnostic reason on failure. No claim of total RSS/CPU bound.

Raw socket wire-byte token bucket1MiB/s burst128KiB, counting upgrade head and raw chunks without double-counting before WS receiver consumption where possible. Ping+pong public events<=4/s burst8; manual bounded pong, no autoPong. Every5s send a bounded nonce ping; missing matching pong10s terminates. No application/native data30s closes; session absolute150s/run absolute180s. Each asynchronous callback checks session generation/closed state and never forwards retired bytes.

Bounded diagnostics512 records/component/session and8MiB process/run output, overflow explicitly fails/stops rather than dropping and passing. No sensitive URL/caps/data payload logging; length/hash/counters/tuple IDs suffice. close idempotently stops admission/timers, closes peers then terminates<=2s, closes owned HTTP/UDP active/retired/pending handles, resolves after completion. Explicit SIGINT/SIGTERM CLI uses normal close path, no unrelated process killing.

## Semantics and risk boundary

ws maxFragments counts nonempty retained payload buffers, not all frames; maxBufferedChunks counts TCP chunks, not bytes. Empty continuation/control behavior and allocation-before-message callback prevent whole-parser memory/CPU claims. Wire bytes/control/time/application queues complement those options, not a second framing parser. Normal browser/native feasibility uses trusted supervisor-created clients/caps only; no malicious ENet is admitted by this release. Native ENet1GiB reassembly/untrusted-map concerns remain outside this component. No public deploy, authority, multiplayer, P0/P1/MVP or universal denial-of-service claim follows.
