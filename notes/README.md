# Worker notes and lead decisions

Use `questions/` for ambiguities, blockers and proposed deviations. Use `handoffs/` for implementation evidence and completion reports. Only the coordinating lead writes `decisions/`, which records resolutions and approved amendments.

Workers create uniquely named files; they do not edit each other's notes or close questions themselves. A note cannot change the scope or status of a contract/ticket. The lead reviews notes during coordination; no automatic background monitoring is implied.

Question naming: `<ticket-id>-<worker>-<short-subject>.md`. Handoff naming: `<ticket-id>-<worker>-<attempt>.md`. Decision naming: `D001-<short-subject>.md`, incremented by the lead.
