## Material findings for MAIN

1. **Actual ws version is now known:** `lib/utilsBundle.js.LICENSE` identifies
   ws@8.21.0 (section at lines 2021–2044) with its MIT copyright/permission text.
   Root Playwright license is Apache-2.0. Whole-bundle redistribution is not MIT
   ws only: retain the full sidecar and applicable root LICENSE/NOTICE/third-party
   notices. No copying/distribution clearance is granted by this report.
2. **Selective destructuring is not a selective import:** ws wrappers are eagerly
   invoked by the whole utilsBundle entry along with unrelated utilities.
   graceful-fs patches shared Node fs.close/closeSync and publishes a global
   queue; debug/env/platform probes and a global signal-exit emitter also exist.
   Listener/socket/client construction remains a later call, not a class definition.
   Optional bufferutil/utf-8-validate/fsevents requires are distinct further native
   initialization risks; runtime resolution was not executed or assumed absent.
3. **Bounds have exact narrower semantics:** maxFragments counts retained nonempty
   payload fragments, not empty/control/all wire frames. maxBufferedChunks counts
   TCP buffer chunks, not bytes/datagrams. maxPayload caps cumulative data-message
   payload, not connection memory/CPU/rate. A future strict-bound claim needs a
   frozen complementary policy, not a passing normal loopback test.
4. **Admission/backpressure/liveness remain gateway responsibilities:** default
   Origin is unrestricted; false handleProtocols does not itself abort upgrade;
   WS v8 also accepted unless explicitly rejected; text is parsed unless caller
   rejects isBinary=false; send has no drain Boolean or automatic byte cap;
   autoPong is not a watchdog; wsServer.close does not terminate clients or close
   an externally owned HTTP listener. These mechanisms were inspected, not tested.
