# D001 MVP scope and tester interface direction

Authority: direct human project owner replies in the coordinating chat on 7 November 2026. Recorded by coordinating lead.

## Approved scope

The owner selected the eight-player MVP with squads up to four, a fifteen-minute match, a small Blackwood map, universal revive, basic loot/barricades, one Predator, Director-lite and extraction. A four-player core loop is an earlier milestone.

The owner also requested an interface for LLMs to play as testers. The subsequent direction was to use game state without requiring screenshots, and to defer detailed interface design because it is not the current priority.

## Contract effect

The eight-player scope replaces the pending scope choice in revision 0.1 drafts. The LLM tester capability is included as a deferred contract requirement. T013 is a placeholder and cannot be released until the owner and lead approve its separate contract. No provider, transport or observation schema is approved here.

## Limits

This decision approves the selected scope and tester direction only. It does not approve every proposed numerical gameplay value or release any phase/ticket. The contract set remains DRAFT until owner/lead review is complete. No workers were dispatched by this decision.
