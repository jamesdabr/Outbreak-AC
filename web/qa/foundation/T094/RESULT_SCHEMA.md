# Private T094 report schema — version1, review required

Only `module.exports = {measureFoundation}` is public. `await measureFoundation(page)` accepts exactly the caller-supplied already joined Page, no options, URLs, callbacks, overrides or hooks. No other controller consumes this private report until MAIN accepts it. This is preparation, not an execution or integration grant.

The returned JSON-compatible object has kind FOUNDATION_COMPONENT_OBSERVATIONS and schema_version1. It has no aggregate PASS, authority, P0 or MVP acceptance field. `scope` identifies external caller authorization/identity responsibility. `checks` contains ready_observed_within_15s when observed, cleanup, and component_sequence:FAIL only on sequence failure. Section statuses use PASS/FAIL/NOT_OBSERVED; PASS means that particular observed component check only.

Source identities/mappings and errors remain externally pinned by the supervisor; passing this component does not validate browser authenticity or source/artifact acceptance. Observer rAF time is not native game simulation time. The timing-frame relation at completed publication is timing.frame_id+1===foundation.frame_count; old native-relay movement is not Outbreak authority.

Preparation receipts wrap every scenario with classification FIXTURE_ONLY and actual_browser:false. Fake60s progression is not a benchmark, load result or real visibility/input evidence. Future supervisor integration, raw/encoded transfer availability/cold-warm runs, GPU/console startup, owned process/RSS and human evidence require separate releases.
