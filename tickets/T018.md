## Required outcome

Create a read-only asset/config dependency inventory and deterministic JSON manifest generator for a bounded browser bootstrap profile. Identify what the current client loads before its first frame, which references are optional or dynamic, and which files cannot be included in a shared build without further permission. No asset copying, browser pack creation or source/config modification is authorized.

The generator must not execute CubeScript, source configuration code or imported asset code. Inspect references as data. The tool may identify unresolved dynamic references and require a manually declared supplement; it must not describe static parsing as a proof of complete runtime closure.

## Approved experimental manifest boundary

The lead approves schema version 1, which contains a named profile, explicit normalized repository-relative root paths, a lexically sorted unique entry list, unresolved-reference records and aggregate raw byte counts. Each entry records repository-relative source path, normalized absolute virtual filesystem path, byte length, SHA-256, required/optional classification, inclusion reason/dependency provenance, and license-evidence references/classification. Do not include machine absolute paths, timestamps or environment-specific values in deterministic manifest output.

Use conservative permission classes: `unreviewed`, `restricted`, or `candidate-permitted`. A notice pointer and recorded reasoning are required for the latter two; candidate-permitted is not legal clearance or permission to distribute. A shared-build inventory view must exclude restricted and unreviewed entries and report any missing required dependency as a blocking error; the generator does not create that build.

Include explicit boolean `complete` and `shared_build_ready` fields; they remain false while any required dependency or permission is unresolved. Every required bootstrap asset is either explicitly present with evidence or reported missing/unresolved. Optional profile/auth files may be absent when marked optional. Never include `config/authprivate.cfg`, `config/authpreprivate.cfg`, server password/private files, native user profiles, `.git` or arbitrary checkout files in an inclusion list. Inventory their startup role as excluded private services, without reading secret contents or emitting values.

Paths must be repository-confined after symlink resolution, relative, normalized and unique. Reject absolute source paths, `..` escapes and symlinks escaping the repository. Virtual paths must not escape their designated virtual root or collide after normalization. A manually supplied dynamic supplement must pass the same validation as parsed references.

## Acceptance criteria

1. A root/profile file documents each known startup category and its source reference. It distinguishes mandatory roots, optional profile/private services, selected-map dependencies and unresolved dynamic expressions. No arbitrary full-directory or whole-checkout preload is used.
2. Running the generator twice on unchanged inputs yields byte-identical manifest output and equal hashes/counts. The tool records its Python version separately in execution evidence.
3. An actual checkout inventory includes at least the fallback texture and nested default/monospace font dependencies, or emits a precise missing-reference error. Each included actual entry has length, hash, inclusion reason and permission-evidence status.
4. Fixture checks cover nested include/reference traversal, repeated references/cycles, missing required versus missing optional input, dynamic/unresolved expressions, duplicate/conflicting virtual paths, source traversal and out-of-root symlink attempts. Failure exits nonzero and names the parent reference and rejected path.
5. The permission report demonstrably prevents restricted/unreviewed required items from being presented as a shared-build-ready closure. Existing personal-use/noncommercial model notices remain visible as blockers; no license is changed or permission inferred from engine licensing.
6. The handoff provides a raw-size summary, the smallest justified bootstrap candidate list and an explicit unresolved list. It states that no media was repackaged and no actual browser load was verified by this ticket.
