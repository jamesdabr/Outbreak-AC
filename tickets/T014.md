## Required outcome

Demonstrate a minimal AssaultCube-derived client rendering and navigating a small map in a real web browser. Identify the actual graphics/runtime/dependency changes and browser constraints before committing the game to this client foundation.

## Acceptance criteria

1. Load client code and assets from a local development URL into the designated browser; no native client process or video-streaming substitute.
2. Render and navigate the test map with working keyboard/mouse input, pointer capture and basic audio under browser gesture rules.
3. Record startup/download, memory and frame measurements on named hardware/browser versions; identify visual or feature regressions.
4. Provide reproducible code/build steps and a concrete compatibility gap report; preserve unrelated prototype changes.

No new Outbreak gameplay, engine switch, broad renderer modernization, multiplayer implementation, mobile promise or public hosting.
